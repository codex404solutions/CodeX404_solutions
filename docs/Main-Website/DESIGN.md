# CodeX404 Solutions — Main Website Design System

## 1. Design Philosophy
The site should feel like a modern international technology company rather than a local web agency.

Keywords:
- premium
- technical
- calm
- confident
- precise
- modern
- trustworthy

## 2. Color Tokens
```css
--midnight: #07111F;
--deep-navy: #0B1F3A;
--electric-blue: #2563EB;
--cyan: #22D3EE;
--violet: #7C3AED;
--soft-violet: #A78BFA;
--white: #FFFFFF;
--slate: #94A3B8;
--light: #F8FAFC;
--dark-text: #0F172A;
```

## 3. Gradient
Signature gradient:
```css
linear-gradient(135deg, #2563EB, #7C3AED, #22D3EE)
```
Use selectively for:
- CTA accents
- hero highlights
- icons
- borders
- data visualizations

## 4. Typography
Preferred:
- Inter
- Manrope
- Plus Jakarta Sans

Typography hierarchy:
- display headline
- H2 section title
- H3 card title
- body
- metadata
- CTA

Do not make body text too small.

## 5. Header
Desktop:
Logo | Solutions | AI | Automation | Industries | Work | Process | About | CTA

Mobile:
Logo | menu | primary CTA.

## 6. Hero
Dark background.
Large headline.
Short supporting paragraph.
Two CTA buttons.
Abstract technical visual.

Visual concepts:
- flowing data architecture
- modular software blocks
- AI nodes
- automation paths
- elegant dashboard fragments

Avoid generic humanoid robots.

## 7. Capability Cards
Each card:
- icon
- title
- short description
- outcome
- arrow

## 8. Problem-to-Solution Section
Use a visual transformation:
```text
Manual Process
     ↓
Disconnected Tools
     ↓
Software + AI
     ↓
Automated Workflow
     ↓
Better Operations
```

## 9. AI Section
Explain practical use cases:
- support
- knowledge retrieval
- document processing
- sales
- analytics
- internal assistants
- agents

## 10. Case Studies
Cards should visually prioritize:
- industry
- problem
- solution
- measurable result if verified

## 11. Process
Use a horizontal desktop timeline and vertical mobile layout.

## 12. Security
Use restrained technical visuals:
- access control
- secure APIs
- backups
- monitoring
- deployment

Do not use fake security badges.

## 13. CTA
Large, calm, high-contrast CTA.

Example:
**Have a business problem software can solve?**
Let's turn it into a practical solution.

## 14. Footer
Columns:
Solutions
Industries
Company
Resources
Contact
Social

Include privacy/terms and company information.

## 15. Accessibility
- WCAG 2.2 AA-oriented
- contrast
- keyboard
- focus
- labels
- reduced motion
- semantic structure
- accessible error messages

## 16. Responsive Rules
Mobile:
- no horizontal overflow
- 44px-ish touch targets
- compressed navigation
- readable typography
- stacked cards
- simplified complex visualizations
